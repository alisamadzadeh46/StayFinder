Architecture

Six services, one docker compose up.

$ docker compose up -d --build

 ✔ nginx          → :80

$ python manage.py createsuperuser

Get started

Up and running in minutes.

Clone the repo, copy the env file, and run one command. The full platform — Django backend, React frontend, PostgreSQL, Redis, and Celery worker — is ready out of the box.

View on GitHub Explore features 
# 1. Clone & configure
git clone https://github.com/alisamadzadeh46/StayFinder.git
cd StayFinder
cp .env.example .env

# 2. Boot the stack
docker compose up -d --build

# 3. Initialize
python manage.py migrate
python manage.py createsuperuser

# Open http://localhost:8000
